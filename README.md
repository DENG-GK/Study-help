## ✨ 功能特点

| 功能 | 说明 |
|------|------|
| 📋 **待办管理** | 添加、完成、删除今日任务 |
| 🍅 **番茄钟** | 25分钟专注 + 5分钟休息 |
| ⏱ **时长记录** | 记录每日专注学习时长 |
| 📊 **今日统计** | 显示专注时长、完成任务、番茄数 |
| 📖 **单词任务** | 快速添加背单词任务 |
| 🎨 **科技感界面** | 深色主题，悬浮窗口 |

## 🚀 安装步骤

### 方法一：使用启动脚本（推荐）

1. 双击运行 `启动.bat`
2. 首次运行会自动创建虚拟环境并安装依赖
3. 之后每次双击即可启动

### 方法二：手动安装

```bash
# 1. 进入项目目录
cd E:\学习用\考研\学习助手

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
venv\Scripts\activate

# 4. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 5. 运行程序
python main.py
```

## 🎮 使用说明

### 番茄钟
1. 点击 **[▶ 开始]** 启动25分钟专注计时
2. 专注结束后自动切换到5分钟休息
3. 点击 **[↺ 重置]** 可重新开始

### 待办事项
1. 点击 **[+ 添加]** 创建新任务
2. 点击任务前的复选框标记完成
3. 点击 **[×]** 删除任务

### 学习时长记录
1. 点击 **[⏱ 开始记录学习时长]** 开始计时
2. 学习结束后再次点击停止
3. 时长会自动记录到今日统计

### 单词任务
1. 点击 **[📖 添加单词任务]**
2. 输入要背的单词数量
3. 自动创建待办任务

## 📊 数据存储

所有数据保存在 `data/` 文件夹：
- `todos.json` - 待办事项
- `study_records.json` - 学习记录（按日期）

数据格式为JSON，可以手动编辑或备份。

## 🔧 设置开机自启动（可选）

1. 按 `Win + R`，输入 `shell:startup`，打开启动文件夹
2. 将 `启动.bat` 的快捷方式放入该文件夹
3. 下次开机会自动运行

## ❓ 常见问题

**Q: 程序打不开？**
A: 确保已安装 Python 3.8+，并且添加到了系统PATH

**Q: 界面显示异常？**
A: 尝试更新 customtkinter: `pip install --upgrade customtkinter`

**Q: 数据丢失了？**
A: 检查 `data/` 文件夹，数据以JSON格式保存
