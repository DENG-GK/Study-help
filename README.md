## 🚀 安装步骤

### 方法一：使用启动脚本（推荐）

1. 双击运行 `启动.bat`
2. 首次运行会自动创建虚拟环境并安装依赖
3. 之后每次双击即可启动

### 方法二：手动安装

```bash
# 1. 进入项目目录
cd E:\学习用\考研\学习助手

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
venv\Scripts\activate

# 4. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 5. 运行程序
python main_new.py
```

## 🎮 使用说明

### 番茄钟
1. 点击 **[▶ 开始]** 启动25分钟专注计时
2. 专注结束后自动切换到5分钟休息
3. 点击 **[↺ 重置]** 可重新开始

### 待办事项
1. 点击 **[+ 添加]** 创建新任务
2. 点击任务前的复选框标记完成
3. 点击 **[⏰]** 设置任务提醒时间
4. 点击 **[×]** 删除任务

### 任务提醒
1. 点击待办事项旁的 **[⏰]** 图标
2. 选择快捷时间或自定义时间
3. 到时间后弹窗提醒

### 学习时长记录
1. 点击 **[⏱ 开始记录学习时长]** 开始计时
2. 学习结束后再次点击停止
3. 时长会自动记录到今日统计

### 单词学习
1. 点击 **[📖 开始背单词]** 进入学习
2. 支持艾宾浩斯遗忘曲线自动复习
3. 可导入自定义单词表

### 统计报告
1. 点击 **[📊 查看详细统计]**
2. 切换 **今日/本周/本月** 查看不同维度
3. 查看饼图（科目分布）和折线图（趋势）

### 主题切换
1. 点击右上角 **[🌙]** 或 **[☀️]** 按钮
2. 一键切换深色/浅色主题

## 📊 数据存储

所有数据保存在 `data/` 文件夹：
- `todos.json` - 待办事项
- `study_records.json` - 学习记录（按日期）
- `words.json` - 单词数据
- `app_settings.json` - 应用设置（主题等）

数据格式为JSON，可以手动编辑或备份。

## ❓ 常见问题

**Q: 程序打不开？**
A: 确保已安装 Python 3.8+，并且添加到了系统PATH

**Q: 界面显示异常？**
A: 尝试更新 customtkinter: `pip install --upgrade customtkinter`

**Q: 数据丢失了？**
A: 检查 `data/` 文件夹，数据以JSON格式保存
